# Domain docs

Before changing a gameplay area, read the relevant root `CONTEXT.md` or `CONTEXT-MAP.md` and applicable `docs/adr/` files when they exist. If absent, continue without creating generic architecture documents.

Use the game's established terms in issues, test names, and implementation notes. Explicitly flag a conflict with an existing ADR instead of silently overriding it.

This repository is single-context: root `CONTEXT.md` and `docs/adr/` are the locations for future domain documentation.
